# P04 — GitHub README and version tags

**Aim:** Write a README using Markdown and create version tags.

**Markdown example**
```markdown
# My Portfolio
A simple portfolio website.

## Technologies
- HTML
- CSS
- JavaScript
```

**Commands**
```bash
git tag -a v1.0.0 -m "First version"
git push origin v1.0.0
git tag
```

**Output:** GitHub displays the README and the version tag appears under Tags.
