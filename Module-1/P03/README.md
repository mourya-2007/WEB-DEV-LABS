# P03 — Feature-branch Git workflow

**Aim:** Create a separate branch, make a change and merge it with a Pull Request.

**Commands**
```bash
git switch -c feature/my-change
git status
git add .
git commit -m "Add a portfolio change"
git push -u origin feature/my-change
```

**Steps:** Open GitHub, create a Pull Request from `feature/my-change` into `main`, review the changes and merge it.

**Output:** A feature branch and a merged Pull Request.

**Screenshot:** Save a screenshot of your Pull Request in the `output` folder.
