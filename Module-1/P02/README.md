# P02 — Portfolio repo with an initial commit

**Aim:** Create a Git repository and save the first version of the portfolio.

**Commands**
```bash
git init
git status
git add .
git commit -m "Initial commit"
```

**Connect it to GitHub**
```bash
git branch -M main
git remote add origin YOUR_GITHUB_REPOSITORY_URL
git push -u origin main
```

**Output:** Git shows the first commit and the project files appear in GitHub.

**Note:** Replace the URL with your own repository URL. Do not run `git init` again inside an already cloned repository.

**Screenshot:** Save a screenshot of the successful commit or GitHub repository in the `output` folder.
