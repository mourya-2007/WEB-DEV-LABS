# P01 — Project folder and terminal navigation

**Aim:** Create a project folder and practise moving between folders in Terminal.

**Commands**
```bash
pwd
mkdir MyPortfolio
cd MyPortfolio
mkdir images css
ls
cd css
pwd
cd ..
```

**Output:** A MyPortfolio folder with images and css subfolders. The terminal shows the current folder.
